# Privacy requests

The company of the Instance is the controller of your data. A Planner answers a request for access by hand.
A request for full erasure, including Time off, is also handled by hand.
Headroom has no export feature.
Ask your Operator for a copy of the database.

Erase personal details removes the name and email of a Person everywhere in Headroom.
This includes the name and email inside stored Webhook Events.
Headroom deletes each Event 30 days after it creates the Event.
Headroom cannot recall an Event that a Webhook receiver already got.
