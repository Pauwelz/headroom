# Time off calendar

The Time off calendar shows who is off on each day. Every Person can open it.
The page is read-only. To change Time off, use the Schedule. See [Schedule view](schedule.md).

## Read it

- The page shows one month as a wall calendar. It opens on the current month.
- Weeks run from Monday to Sunday. The grid shows full weeks.
  Days of the previous and next month are grey. They still list who is off.
- Each day lists every Person with Time off on that date, sorted by name. Saturday and Sunday are dimmed.
  Time off that covers a weekend lists the Person on those days too.
- A week row grows taller when a day has many names.
- **(afternoon)** after a name means the Time off starts in the afternoon. This is the first day only.
- **(morning)** after a name means the Time off ends in the morning. This is the last day only.
  A one-day half day shows its part.

## Move around

Select the arrows to go to the previous or next month. Select **Today** to return to the current month.
