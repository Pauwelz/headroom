# Headroom

[![OpenSSF Scorecard](https://api.scorecard.dev/projects/github.com/Pauwelz/headroom/badge)](https://scorecard.dev/viewer/?uri=github.com/Pauwelz/headroom)

Headroom is a resource allocation tool for small companies (up to 50 People).
Planners schedule People on Projects over time. Each company runs its own Instance.
Terms are in [GLOSSARY.md](GLOSSARY.md).
